# Architecture decision records

Record a decision here when it is hard to reverse, or when a later reader would otherwise have to reconstruct it from the code. Do not add a record for a decision that has not been made.

## Where

Add a file at `docs/adr/NNNN-short-title.md`. Number records from `0001`. Leave an accepted record in place. To change it, add a new record and set the old record's status to superseded by the new number.

## Format

- Title: `NNNN. Title`
- Status: Proposed, Accepted, or Superseded by `NNNN`
- Context: what forced the decision
- Decision: what was chosen
- Consequences: what becomes easier, harder, or required next
